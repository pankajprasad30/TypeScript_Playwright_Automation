1. Create a directory with name as TypeScriptPractice
2. Open TypeScriptPractice in integrated terminal.
3. initiliaze the a package with the command
   ->  npm init -y
   -> it will create package.json file in TypeScriptPractice folder.

4. install Typescript with below command
   -> npm install --save-dev typescript
   -> verify the installation is succesful
   -> npx tsc --version : Version 7.0.2


5. Create Typescript Configuration.
   -> npx tsc --init
   -> it will create tsconfig.json file in TypeScriptPractice folder.

6. install ts-node dependency on TypeScriptPractice
   -> npm install --save-dev typescript ts-node

Configure Code Runner
If you want to continue using the Run Code button, we can configure Code Runner to use npx ts-node.

In VS Code:

File → Preferences → Settings

Search for:

code runner executor map

Find:

Code-runner: Executor Map

Click:

Edit in settings.json

Add/modify the TypeScript entry:

"code-runner.executorMap": {
    "typescript": "npx ts-node"
}

If you already have an executorMap, don't create a second one. Just change the TypeScript line.

For example:

{
    "code-runner.executorMap": {
        "javascript": "node",
        "typescript": "npx ts-node"
    }
}
